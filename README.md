# VolonTweet

## Dev setup

### Databases (Docker)

- Start:
  - `docker compose up -d`
- Stop:
  - `docker compose down`

### Run backend

- `cd backend`
- `npm install`
- `npm run start:dev`

### Run frontend

- `cd frontend`
- `npm install`
- `npm run dev`

### VSCode Extensions

- `Neo4j for VS Code`
